# Aircup

Aircup is a self-hosted local-first media and file streaming server built with Go and React.

It lets you share and stream files across devices on the same network using a single portable binary.

- No cloud.
- No account.
- No Docker required.
- No external dependencies.

## Features
- Single binary deployment
- Local-first architecture
- Stream videos, audio, images, and files
- Modern React frontend
- Embedded web UI inside Go binary
- QR code sharing
- mDNS local network discovery
- Secure filesystem sandboxing
- Fast HTTP streaming
- Works fully offline on LAN/hotspot networks
